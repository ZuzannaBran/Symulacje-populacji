# Symulacje populacji

Projekt porównujący dwa sposoby symulacji ruchu lotki.

- **Model matematyczny** – symulacja ruchu lotki oparta na równaniach fizycznych.
- **Model eksperymentalny** – próba odwzorowania tego samego ruchu bez ścisłego modelu matematycznego, z większym udziałem losowości.

**Cel:** Porównanie wyników obu podejść i sprawdzenie, jak model losowy odwzorowuje zachowanie modelu fizycznego.
